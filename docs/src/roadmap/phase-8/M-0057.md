## 🎯 Objective

Fix the root cause of the blocky, shimmering textures (all object textures are point-sampled with anisotropy 1) and build the measurement tooling the rest of Phase 8 is judged by.

### Phase B: Sampler (T1)
- [x] One function builds the object-texture sampler (`opts_bevy::texture_filter::object_sampler`): repeat addressing, linear magnification/minification, linear mipmap filtering, anisotropy from the setting. `repeat_sampler()` no longer relies on `Default::default()`.
- [x] Used by `ContentLoader::texture`, hot reload (`hot_reload/cache.rs`) and text textures. **Decision (text textures):** they use the same sampler and get a generated mip chain like every other uncompressed texture. Text is rendered once at the size the mesh needs, so trilinear filtering only matters at a distance, where a chain removes shimmer; at close range linear magnification of a 1:1 texture is at most slightly soft. If screenshots of signs show a loss of legibility, text gets `Linear`/`Nearest` mipmap filtering and anisotropy 1 (a one-line change in `text_texture.rs`).
- [x] Settings entry *Texture filtering* (Display & Sound tab; *status sync 2026-10-25: since M-0063 it is the `texture_filtering` descriptor on the **Graphics** page, `crates/opts-game/src/settings_registry/builtin/graphics.rs`*): Off (nearest) / 4× / 8× / **16× (default)**; applies to textures loaded afterwards, and live through hot reload. `--texture-filter off|4|8|16` overrides it for one run (not persisted). *Off* also skips mip generation.
- [x] Tests: every loader path uses the shared sampler (`tests/shared_sampler.rs`); the descriptor values; settings round trip and defaults for databases without the key.

## ✅ Acceptance Criteria
- High-frequency energy on the reference views is at least 15 % below the nearest-filter baseline (measured on the proposal's experiment: −15 % to −19 %).
- No change in text-texture legibility (screenshot check of three signs) and no regression in the ground shader.
- The harness reproduces its own numbers on a second run of the same build (±1 %).
- `cargo fmt`, `clippy -D warnings`, `cargo test --workspace`, rustdoc `-D warnings` pass.
