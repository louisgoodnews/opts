## 🎯 Objective

Fix the root cause of the blocky, shimmering textures (all object textures are point-sampled with anisotropy 1) and build the measurement tooling the rest of Phase 8 is judged by.

---

## 📦 Deliverables & Tasks

### Phase A: Measurement harness (T0)
- [ ] Reference view set: 6–8 fixed camera positions (street at noon, grazing pavement, foliage, façade, vehicle interior, dusk, a far-distance view) on three maps, defined as data (map, entry point, camera pose, hour) in `docs/src/roadmap/phase-8/` or a data file next to the tool.
- [ ] `opts-tools image-metrics <a.png> [<b.png>]`: mean saturation, luminance mean / standard deviation / darkest pixel, high-frequency energy (Laplacian), and the difference between two images; pure Rust, no external dependency.
- [ ] A scripted A/B run (control protocol `camera.teleport` + `screenshot`, throw-away settings and a copy of the decoder cache) that writes images and metrics **outside** the repository (`~/.local/share/opts/benchmark/`); the commands are documented.
- [ ] Count the DDS files whose mipmap chain `dds_to_bevy_image` drops today (Q-TQ03) and record texture VRAM and load time of the reference maps.

### Phase B: Sampler (T1)
- [ ] One function builds the object-texture sampler: repeat addressing, linear magnification/minification, linear mipmap filtering, anisotropy from the setting. `repeat_sampler()` no longer relies on `Default::default()`.
- [ ] Used by `ContentLoader::texture`, hot reload (`hot_reload/cache.rs`) and text textures (decision recorded in the spec; text keeps readability at close range).
- [ ] Settings entry *Texture filtering*: Off (nearest) / 4× / 8× / **16× (default)**; applies to textures loaded afterwards, and live through hot reload.
- [ ] Tests: every loader path uses the shared sampler; the descriptor values; settings round trip.

---

## ✅ Acceptance Criteria
- High-frequency energy on the reference views is at least 15 % below the nearest-filter baseline (measured on the proposal's experiment: −15 % to −19 %).
- No change in text-texture legibility (screenshot check of three signs) and no regression in the ground shader.
- The harness reproduces its own numbers on a second run of the same build (±1 %).
- `cargo fmt`, `clippy -D warnings`, `cargo test --workspace`, rustdoc `-D warnings` pass.
