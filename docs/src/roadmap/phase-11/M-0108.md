## 🎯 Objective

The player opens a full-screen map in game (M), pans and zooms it, sees their own position and heading, and can leave the session for another map from the Alt menu without going back to the main menu, keeping vehicle and time where that makes sense.

**What exists already (build on it, do not duplicate):**

- The bottom-right mini map ([M-0071](../phase-9/M-0071.md), [mini map architecture](../../architecture/minimap.md)) draws the lane-graph road paths into a texture at <= 10 Hz with discrete and speed-based zoom (100 m-1 km), north-up or heading-up, toggle F7; the drawing code is `crates/opts-game/src/hud/minimap/` (`source.rs`, `raster.rs`). A full-size map reuses that source and rasteriser; only a viewport (pan, zoom, larger texture) is new. Path recognition for the mini map is a separate research branch ([minimap path recognition](../../architecture/minimap-path-recognition.md)).
- Sessions with several vehicles and the Alt menu ([in-game vehicle menu](../../architecture/in-game-vehicle-menu.md), [session vehicles](../../architecture/session-vehicles.md)) exist; the session environment (date, time, weather) is one resource ([session environment](../../architecture/session-environment.md)); session save/restore is specified in [session save](../../architecture/session-save.md) (M-0069).
- There is no way to change the map during a running session today; the map is chosen in the new-game wizard.

---

## 🔍 Scope

**In scope:** (a) full-size map: key M toggles; drag pans, wheel zooms, Esc (or M) closes; shows the player vehicle's position and heading, session vehicles and the rest of the loaded map's roads; opening the map pauses nothing; (b) in-game map switching: an Alt menu page *Change map* that lists installed maps, then reloads the session on the chosen map; vehicle and time carry over where sensible (same vehicle model, session environment), and the player is asked where the target map offers no sensible equivalent (spawn point choice).

**Out of scope:** route planning or waypoint markers, showing unloaded tiles with full road detail (the map shows what the lane graph holds plus a coarse tile outline), mini map redesign, hot-swapping tiles without a reload, multiplayer.

## ✅ Acceptance Criteria

1. Pressing M during a drive opens the full-size map within one frame and shows the player's position and heading at the correct location (checked against the vehicle transform to within 1 m at zoom 100 m); Esc closes it within one frame and driving input returns.
2. Dragging pans by the dragged distance (error <= 1 px) and the wheel zooms toward the cursor so the point under the cursor stays within 2 px; zoom is clamped to the documented range.
3. With the map open the simulation keeps running (vehicle position advances) and the open map costs at most 2 ms per redraw; while idle it redraws only on viewport change or at 2 Hz for markers.
4. Choosing *Change map* in the Alt menu and confirming loads the target map without returning to the main menu; the same vehicle model and the session time are preserved; when the vehicle cannot be spawned a prompt appears and no crash or empty world results.
5. The map shown is the layout of the loaded roads: on Berlin-Spandau a screenshot recipe lists road path coverage comparable to the mini map at the same zoom.

All gates pass for milestones that change code (`cargo fmt`, `cargo clippy -D warnings`, `cargo test --workspace --all-features`, `./scripts/local-ci.sh`); no unsafe code; no OMSI asset committed.

## ⚠️ Risks & Mitigations

| Risk | Mitigation |
| :--- | :--- |
| Large maps make the redraw expensive | Reuse the mini map's cached path set; rasterise only the viewport; budget and degrade by line decimation |
| Map switching leaks state from the old map (entities, streaming, AI) | Go through the one session teardown path; add a leak test that counts entities after switching twice |
| Vehicle semantics differ between maps (no matching spawn point) | Spawn-point prompt; never silently place a vehicle |

## 📝 Notes & Logs

**2026-10-19, full-size map (branch `agent/full-size-map`).**

* **Key: F6, not M.** `M` is OMSI's default for *engine start* (`kw_m_enginestart`, the first-run default of the vehicle key `engine_start`); taking it would break every OMSI keyboard layout and the existing key tests. F6 sits next to F7 (mini map), was unused, and is reserved against script bindings (`OPTS_RESERVED_KEYS`). Say so if M with a different engine key is preferred.
* **Code:** `crates/opts-game/src/hud/fullmap/` (`viewport.rs` pure maths, `mod.rs` state, keys, mouse, overlay, redraw); the drawing is the mini map's `raster` with `render_with_unit` (marker size and no north mark for the large canvas). Protocol 1.15.0 `hud.fullmap`. The map holds `MenuModalActive` through `FullMapState::holds_input` (included by the vehicle menu's flag), so driving, camera and script input stand still (`drive.set` answers `1009` while it is open, checked live) and Esc closes the map instead of opening the pause overlay.
* **Checked live on Berlin-Spandau (release build, 1920 x 1013 window):** F6 opens in one frame centred on the vehicle with the heading arrow; the wheel zooms (3 notches: 1000 m to 579 m span); span 300 m and 8 km work; `sim.get` time keeps advancing while the map is open; `drive.set` is refused while open and works after Esc. Redraws: 1.8 to 2.6 ms at a 1024 px texture (the first one 3 to 5 ms, cold), a little over the 2 ms of criterion 3: the texture is capped at 1024 px and arcs are cut into chords of six pixels or more to stay close; a bigger saving needs decimation of the lane graph (paths of both directions overlap) and is left open.
* **Not done:** the coarse tile outline for unloaded areas (the map shows the loaded lane graph only), and a rebinding setting for the key (the help page lists F6; the vehicle-key page does not cover OPTS keys). Mouse drag is covered by the unit tests of the viewport maths (a dragged point stays under the cursor within 1 px) and by the system; it could not be driven live because the control protocol moves the mouse relatively and does not set the window cursor.
* **Screenshot:** [full-size map at 1 km and 8 km span](../../architecture/img/fullmap-1km-8km.png).
