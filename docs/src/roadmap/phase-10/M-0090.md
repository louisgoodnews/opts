## 🎯 Objective

Fix the content defects the project lead found while playing, each one traced to a source asset or a loader bug with a regression test.

## 📦 Deliverables & Tasks
- [x] **R-34 pedestrians** (re-checked 2026-10-18, MI-0059): a few pedestrians have scrambled meshes — identify the human models and the cause (keyed decode below the agreement threshold, rejected meshes, skeleton/part mismatch).
- [x] **R-35 Hamburg maps** (fixed with M-0066 on 2026-10-18, MI-0060): loading objects fails partially, leaving absent or scrambled objects — per-object load results of the Hamburg maps (all of them), error classes (parse failure, missing file, decode rejection, timeout, budget cut-off), fix by class.
- [~] **R-36 load time** (the loading screen answers within 0.3 s per frame since M-0089 step 1; the cold model load, Q-SP01, is open): objects take a long time to load — measure per-stage time (decode, cache hit rate, parse, texture), find the slow classes, fix or schedule (shared with [M-0089](../phase-4/M-0089.md) and the decode cache).
- [x] **R-37 parked cars** (MI-0029, MI-0046, MI-0047, MI-0053, MI-0056): many parked-car scenery objects are partially transparent and show the interior — check alpha/`[matl_alpha]`/glass material handling and the `[alphascale]` rule (MI-0029), render order and double-sided flags; fix without making real glass opaque.
- [x] **R-38 driving cars** (implemented 2026-10-11 by M-0049, verified live 2026-10-18, MI-0061): AI cars have no wheel animation — wheel rotation from `[newanim]` / script variables for AI vehicles (speed to wheel rotation), same path as player vehicles.
- [x] **R-39 Wuppertal driving cars transparent** (re-checked 2026-10-18, MI-0061) — same family as R-37; verify on Wuppertal.
- [x] **R-41 Schwebebahn stations (Wuppertal)** (re-checked 2026-10-18, MI-0062): stations do not load entirely — find missing parts (scenery objects, splines, attachments, spline-attached objects).
- [ ] **R-42 Wuppertal T-crossings** (not reproduced, needs a position from the project lead, MI-0063): some are flipped by 90° — rotation convention of junction/spline objects or crossing templates; fix and add a regression fixture.
- [ ] Use the scene trace (`trace.pick`, M-0087) to map each defect to an asset reference; register in the mesh issue registry; each fix with a test; no per-asset special cases unless documented as content defects.

## ✅ Acceptance Criteria
- Each listed defect is either fixed (screenshot evidence outside the repository, regression test) or registered as a content defect with evidence.
