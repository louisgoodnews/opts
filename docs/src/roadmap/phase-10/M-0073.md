## 🎯 Objective

OPTS provides a **world physics system** (gravity, ground contact, friction, air, collisions, coupling); **each vehicle defines its own behaviour** through its data (mass, centre of mass, axles, wheels, springs and dampers, brake system, drivetrain) which the world respects. Today a generic model dominates.

## 📦 Deliverables & Tasks
- [ ] **Architecture doc** (`docs/src/simulation/vehicle-dynamics.md`): the split between *world physics* (shared solver, ground, tyres/contact, gravity, collisions) and *vehicle definition* (`VehicleDynamicsSpec` built from `.bus`/`.ovh`/`.cfg`/constfiles): mass (empty + passengers later), inertia, axle positions and loads, wheel radius, suspension (spring rate, damping, travel, anti-roll if defined), brakes (service/parking/retarder, pressure model, brake force distribution), drivetrain and gearbox. Document which OMSI fields carry each value and which are unknown ❓ (docs first, corpus statistics).
- [ ] Data audit over the corpus: which vehicles define which parameters, distributions, missing/implausible values; fallbacks documented.
- [ ] Per-axle suspension: spring-damper per wheel with ground contact from the terrain/road mesh; body pitch, roll and heave; visual wheel and body motion; articulated units share the model ([M-0053](../phase-4/M-0053.md)).
- [ ] Brakes: per-axle brake torque with pneumatic build-up and distribution, parking brake holding on slopes, ABS-free baseline, brake fade out of scope; scripts' `brake` variables stay authoritative where the vehicle script drives them.
- [ ] Mass and load transfer in acceleration and braking; stopping distance and gradient behaviour validated against plausible real values (tests with documented tolerance).
- [ ] Debug overlay of per-wheel load, spring compression and brake force (developer panel).
- [ ] Control protocol: `vehicle.dynamics` query (spec and live per-wheel state).

## ✅ Acceptance Criteria
- Two vehicles with different mass and axle layouts brake and ride visibly and measurably differently in the same scenario; a loaded-down heavy articulated bus needs a longer stopping distance than a light one (test).
- Every parameter used is traceable to a vehicle file field or a documented default; the spec page lists unknown semantics as open questions.
