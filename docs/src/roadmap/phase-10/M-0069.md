## 🎯 Objective

Save the running session and restore it, with a format that grows by **sections** so weather, timetables, passengers, AI traffic and more join without rewrites or broken old saves.

## 📦 Deliverables & Tasks
- [x] **Design doc and ADR** (`docs/src/architecture/session-save.md`): a versioned container (`magic`, `format_version`, `opts_version`, content fingerprint of map and vehicles) holding independent **sections** keyed by id (`session`, `vehicles`, `time`, `camera`, `settings-overrides`, later `weather`, `timetable`, `passengers`, `traffic`, `scripts`). Unknown sections are preserved and ignored, a missing section takes defaults, each section has its own version and a migration function.
- [x] A `SaveSection` registry (like the settings and HUD registries): a feature crate registers *capture* and *apply* functions; the save system owns file I/O, atomic writes (temp + rename), backups and corruption handling.
- [x] First sections: map and entry point, date/time and weather preset, session vehicles ([M-0068](M-0068.md): pose, velocity, gear, brake state, script variables, doors/lights), active vehicle, camera.
- [x] UI: *Save game* in the pause overlay; **Load game** on Home becomes real (remove its NotYet entry); save list with name, map, vehicle, play time, date; autosave and quick-save keys; delete/rename with confirmation.
- [x] Restore path through the normal loading screen; failure reporting follows the error template (missing map or vehicle: *Choose another*, *Back*).
- [x] Control protocol: `session.save`, `session.load`, `session.saves`.
- [x] Tests: round trip, forward-compat (unknown section), backward-compat (old version fixtures), corrupted file, missing content.

## ✅ Verified
Live on Berlin-Spandau (see the [progress file](../../dev/progress/session-save.md)): positions, velocities, gear, brake state, all script variables, clock, odometer, active vehicle and camera identical after save, leave to Home, *Load game*; AI traffic is not restored (documented).

## ✅ Acceptance Criteria
- Save in a running drive, quit, load: map, time, vehicles and their poses and script state match within tolerance (documented per field); the driven distance continues.
- Adding a new section requires no change in the save system itself (demonstrated by a test section registered in a test).
