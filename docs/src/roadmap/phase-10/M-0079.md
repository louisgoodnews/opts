## 🎯 Objective

Make the *state* of the texture coordinates of every scrambled mesh in an installation visible and permanent: which vehicles and objects have unreliable UVs and how many, on demand, with a tool, so that a defect like the MAN NL/NG corruption is a line in a report and never a surprise on screen.

## ✅ What is already done (P-1013 phases A–C, merged into `master` 2026-10-13)
- Ground truth: 2,476 plain/keyed twin pairs (881,573 vertices) found in the installation; `uv_truth`, `uv_step_eval`, `scripts/uv_truth_analysis.py` and the calibration tools.
- Decoder: lattice stage (offset-aware plane seeding), welded smooth stage, evidence strength per vertex; **77.07 % → 85.14 % exact** on the truth set (84.82 % end to end).
- `UvQuality` per vertex (`Exact` ≥ 99 %, `Recovered` 90–99 %, `Unreliable` < 90 %, calibrated on the truth set), stored in the decode cache (v7); `WARN` per mesh and per vehicle above 10 % unreliable vertices; incident file per unreliable mesh (see the bug report).
- Tests `crates/opts-core/tests/uv_decoder.rs`; the blank-parameter parse fix.

## 📦 Deliverables & Tasks (deferred)
- [ ] **Fleet decode:** run the decoder over every keyed `.o3d` of the installation and record per file: vertices, `Exact`/`Recovered`/`Unreliable` counts, wall time (`uv_truth`'s walker is the starting point; the full truth-set run takes about 6 minutes on 16 threads).
- [ ] **Coverage report** `docs/src/meta/uv-decoder-coverage.md`: totals, rates, vehicles with more than 1 % unreliable vertices, distribution; the per-mesh table (vehicle, mesh, vertices, exact %, unreliable %) sorted by unreliable share; the top 50 become the "known broken" list the game reports on load.
- [ ] **`opts-cli validate-uvs --input "<OMSI 2>"`** runs the same on a folder tree and writes the report; routine part of the validation suite.
- [ ] **Visual spot-check** of each vehicle with more than 1 % unreliable vertices (screenshot of the affected geometry); MAN NG272 cockpit, interior and exterior confirmation with the final decoder (state on 2026-10-13: passenger view clean, IBIS/ticket console still partly wrong, 47 % of the vehicle's UVs unreliable).
- [ ] **Docs:** complete `docs/src/architecture/uv-decoder.md` (scramble facts as reconstructed, failure modes, quality flags, fallback) and the bug report (symptom with screenshots, lessons); update `docs/crates/opts-core.md`.
- [ ] **CI item:** a nightly or on-demand job that decodes a reference installation and fails if the unreliable rate exceeds a threshold.

## ✅ Acceptance Criteria
- The coverage report exists, is reproducible with `opts-cli validate-uvs`, and lists every vehicle above 1 % unreliable vertices with its top meshes.
- Loading a listed vehicle logs the existing per-vehicle warning; no mesh with unreliable UVs is silent.
- NG272 screenshots (cockpit, interior, exterior) with the final decoder are in the bug report.

## ❓ Open / ideas (not scheduled)
- The scrambler's chain `s` is unreproduced; a reconstruction with the 881k labelled vertices and `q = n·s mod 8000` is the only route to exact UVs on meshes without a twin (declined for now).
- Region-level solving without twins reaches 85 %; a hinge-interpolated fallback was measured worse than the best guess and is not used.
