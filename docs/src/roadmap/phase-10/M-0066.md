## 🎯 Objective

Every parked car, bus, building and lantern post renders as authored: no scrambled, missing or transparent meshes. Four concrete reports start the work (R-01 parked cars, R-09 BRT Citaro, R-17 buildings, R-18 lantern posts): **parked cars** (scrambled, missing or transparent), the **BRT Citaro** (UV and mesh issues), **buildings** (flipped meshes, misaligned textures) and **lantern posts** (scrambled meshes).

## 📦 Deliverables & Tasks
- [x] Reproduce R-01 (done 2026-10-18: the scene trace of three maps lists 489 + 21 parked cars as failed; the registry has MI-0056): list the parked-car vehicles (`Vehicles/` and the map's parked-car lists) that show defects; one catalogue id and one screenshot-free description per defect in the mesh issue registry.
- [x] Classify each (parser/decoder coverage MI-0056, layout veto MI-0057, size limit MI-0058): parser bug (index/stride/UV decoding), material/alpha binding (transparent), LOD or `[lod]` selection (missing), animation/pivot, or genuine content defect.
- [x] Fix root causes in `opts-core`/`opts-bevy` with regression tests (done 2026-10-18); no per-asset special cases unless the asset is documented as a content defect.
