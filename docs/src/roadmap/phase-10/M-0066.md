## 🎯 Objective

Every parked car and every bus renders as authored: no scrambled, missing or transparent meshes. Two concrete reports start the work: **parked cars** (some meshes scrambled, missing or transparent) and the **BRT Citaro** (UV and mesh issues).

## 📦 Deliverables & Tasks
- [ ] Reproduce R-01: list the parked-car vehicles (`Vehicles/` and the map's parked-car lists) that show defects; one catalogue id and one screenshot-free description per defect in the mesh issue registry.
- [ ] Classify each: parser bug (index/stride/UV decoding), material/alpha binding (transparent), LOD or `[lod]` selection (missing), animation/pivot, or genuine content defect.
- [ ] Fix root causes in `opts-core`/`opts-bevy` with regression tests; no per-asset special cases unless the asset is documented as a content defect.
- [ ] Reproduce R-09 (BRT Citaro): find the defective meshes by part, decide cause (UV decoder, mirrored/scrambled UV, wrong material binding), fix and add a regression test using the offline UV audit.
- [ ] Re-run the parked-car and bus sample after each fix; record coverage numbers in the registry.

## ✅ Acceptance Criteria
- No scrambled, missing or transparent mesh remains in the sampled parked-car set and the BRT Citaro, or each remaining one is registered as a content defect with evidence.
- Regression tests cover each fixed root cause; the offline audit shows no new outliers fleet-wide.
