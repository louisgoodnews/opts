## 🎯 Objective

Implement high-performance, robust, pure Rust parsers in `opts-core` for OMSI's primary 3D mesh formats (`.o3d` and legacy DirectX `.x`). This milestone transforms raw byte buffers into normalized in-memory mesh representations (`O3d` and `XMesh`) containing verified vertex buffers, index buffers, material tables, and transform matrices, establishing the foundational geometry pipeline required by `opts-bevy` for rendering.

---

## 🔍 Scope

**In Scope:**
- Module `opts_core::formats::o3d` and submodules (`error`, `header`, `chunks`, `vertex`, `index`, `material`, `parse`).
- Parser for `.o3d` format versions 1, 3, 4, 5, and 7 per `o3d.md`.
- Vertex decoding (32-byte stride: positions, normals, UVs).
- Face decoding supporting both 16-bit and 32-bit index buffers.
- Material table decoding (RGBA diffuse, RGB specular, RGB emissive, shininess, texture filename).
- Transform matrix chunk (`0x79`) parsed as explicit 4×4 data.
- Preservation of optional/unknown chunks (e.g. bone weights `0x54`) as raw payload.
- Module `opts_core::formats::x` parsing text and binary DirectX meshes per `x.md`.
- Unit tests using hand-authored byte arrays.
- Integration tests against clean-room mutation fixtures (`t01`–`t07`, `t10`–`t12`).
- Fuzzing / robustness tests verifying graceful errors on truncated or malformed inputs.
- Crate-level and module-level documentation.

**Out of Scope:**
- GPU mesh creation or Bevy rendering logic (belongs in `opts-bevy`).
- Texture image decoding (`.dds`, `.tga`, `.bmp`) (belongs in `opts-assets`).
- Skeletal animation / bone deformation runtime evaluation.
- Writing / serializing meshes back to `.o3d` (deferred to round-trip export tools).
- File I/O inside `opts-core` (parsers accept byte slices `&[u8]`).

## ⚠️ Risks & Mitigations

| Risk | Likelihood | Impact | Mitigation |
| :--- | :---: | :---: | :--- |
| **Unaligned memory reads on irregular vertex streams.** | Low | Medium | Use `from_le_bytes` on byte copies rather than unsafe slice casting (`bytemuck::cast_slice`). |
| **Material string length byte mismatches (exporter anomalies).** | Low | Low | Documented in `o3d.md` anomaly table; enforce bounds checking and return clear `Truncated` or `InvalidUtf8` errors. |
| **32-bit index flag misinterpretation.** | Low | High | Verified against test T05 fixtures; bit 0 explicitly switches index stride from 16 to 32 bits. |
| **Matrix chunk interpretation confusion.** | Low | Medium | Matrix stored as raw row-vector data; coordinate conversions deferred to `opts-bevy` per `coordinates.md`. |
