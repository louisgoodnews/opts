## 🎯 Objective

Implement parsers in `opts-core` for OMSI world scenery objects (`.sco`), splines (`.sli`), tile placement maps (`tile_<x>_<y>.map`), and global scenario manifests (`global.cfg`). This milestone will be activated once the target format specifications are promoted from 🟡 Draft to 🟢 Specified following in-engine mutation test validation (Mutation Kit 2).

---

## 🔍 Scope

**In Scope:**
- Scenery object parsing (`.sco` mesh attachments, bounding boxes, fixed lights).
- Spline profile parsing (`.sli` 2D extrusion profiles, paths, textures).
- Map tile layout parsing (`tile_*.map` object and spline instance declarations).
- Global map manifest parsing (`global.cfg` map metadata, money system bindings).

**Out of Scope:**
- Implementation prior to formal specification promotion to 🟢 Specified.
- Real-time world rendering or spatial acceleration trees (belongs in `opts-bevy`).
