## 🎯 Objective

Implement a high-performance, robust, pure Rust parser in `opts-core` (`opts_core::formats::vehicles::model`) for vehicle rendering manifests (`model.cfg`). This milestone parses flat keyword streams into structured, hierarchical in-memory render trees (`ModelConfig`, `ModelLOD`, `ModelMesh`, `ModelAnim`, `ModelMaterialMod`) capturing mesh references, level-of-detail thresholds, viewpoint bitmasks, conditional visibility bindings, click events, bone attachments, animation hierarchies, and material texture substitutions. This completes the core vehicle asset ingestion pipeline, enabling `opts-bevy` to spawn complete 3D bus entities.

---

## 🔍 Scope

**In Scope:**
- Module `opts_core::formats::vehicles::model` with strongly typed `ModelParseError`.
- Parser for global directives: `[tex_detail_factor]`, `[CTC]`, `[CTCTexture]`, `[texttexture]`, `[texttexture_enh]`, `[scripttexture]`.
- Parser for state switches: `[LOD]` partitioning subsequent meshes into distance tiers.
- Parser for `[mesh]` definitions and scoped attributes:
  - Relative mesh path (`.o3d` or `.x`).
  - Viewpoint bitmask (`[viewpoint]`: Always = 0, Outside = 1, Inside = 2, AI = 4).
  - Interior lighting assignments (`[illumination_interior]`).
  - Conditional visibility (`[visible] <variable> <expected_value>`).
  - Interactivity (`[mouseevent] <event_name>`).
  - Hierarchical linkage (`[mesh_ident]`, `[animparent]`).
  - Skinning attributes (`[smoothskin]`, `[setbone]`).
  - Shadow flag (`[isshadow]`).
  - Animation blocks (`[newanim]` with origin, vector, and script variable driver).
  - Material slot modifiers (`[matl]`, `[matl_change]`, `[matl_alpha]`, `[matl_transmap]`, `[matl_envmap]`).
- Unknown field preservation for round-trip fidelity and forward compatibility.
- Unit tests with synthetic model configurations.
- Integration tests simulating full bus body, interior, and wheel hierarchies.
- Robustness tests verifying graceful handling of malformed or truncated input without panics.
- Crate-level and module-level documentation.

**Out of Scope:**
- GPU mesh creation, texture upload, or Bevy entity instantiation (belongs in `opts-bevy`).
- Dynamic runtime animation matrix evaluation per simulation frame (belongs in `opts-sim` / `opts-bevy`).
- Dynamic runtime text rasterization for texttextures (belongs in `opts-assets`).
- File I/O inside `opts-core` (parsers accept string slices or byte slices `&[u8]`).

## ⚠️ Risks & Mitigations

| Risk | Likelihood | Impact | Mitigation |
| :--- | :---: | :---: | :--- |
| **Stateful keyword scoping ambiguity (properties before first mesh or between LODs).** | Medium | Medium | Maintain an explicit state machine: global properties attach to root; properties following `[mesh]` attach to current mesh until next `[mesh]` or `[LOD]`. |
| **`[newanim]` sub-block variable line layouts.** | Medium | Medium | Match recognized sub-identifiers (`origin_trans`, `anim_rot`, etc.) consuming exact parameter counts, while treating unknown sub-lines gracefully. |
| **Viewpoint bitmask combinations.** | Low | Low | Model `Viewpoint` as a typed bitflags struct or helper method checking bit flags (1 = Outside, 2 = Inside, 4 = AI). |
| **Windows-1252 character encoding in texture names and comments.** | Low | Low | Leverage `formats::text::decode_bytes` for seamless CP1252 fallback. |

## 📋 Implementation Plan

### 1. Preconditions
- `crates/opts-core` compiles with `#![deny(unsafe_code)]`.
- `model_cfg.md` format specification is documented.
- Shared text utilities in `opts_core::formats::text` are available.

### 2. Sequence of Steps
1. **Define Error Types (`formats::vehicles::model::error`)**:
   - Create strongly typed `ModelParseError` enum with `thiserror`.
2. **Define AST Data Model (`formats::vehicles::model::ast`)**:
   - Define `ModelConfig`, `ModelLOD`, `ModelMesh`, `ModelAnim`, `AnimType`, `ViewpointFlags`, `MaterialMod`.
3. **Implement Stateful Parser (`formats::vehicles::model::parse`)**:
   - Build sequential scanner dispatching global commands, `[LOD]`, `[mesh]`, and scoped sub-properties.
   - Implement `[newanim]` sub-block parser.
4. **Expose Public API (`formats::vehicles::model::mod`)**:
   - Re-export AST, parser, and error types.
   - Expose in `formats::vehicles::mod`.
5. **Unit & Integration Testing**:

   - Integration tests in `crates/opts-core/tests/model_parse.rs`.
   - Robustness fuzzing against malformed/random inputs.
6. **Documentation & Quality Verification**:
   - Rustdoc on all public items and module headers.
   - Update `docs/crates/opts-core.md`.
   - Run and pass `cargo clippy` and `cargo fmt`.
