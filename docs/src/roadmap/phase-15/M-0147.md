## 🎯 Objective

Upgrade `scripts/structure_audit.py` to enforce the four AI-token optimization rules (350-line file ceiling, 250-line inline-test separation, 80-line function ratchet, and `too_many_arguments`/`type_complexity` allow ratchet) and wire `structure_audit.py check` and `omsi_uses.py --check` into `scripts/pre-commit` and `.github/workflows/ci.yml`.

---

## 📦 Deliverables & Tasks

- [x] A1 Lower `FILE_LIMIT` in `scripts/structure_audit.py` from `500` to `350` lines of code, and add the **inline-test rule**: any production file (`crates/*/src/**/*.rs`, excluding `tests.rs`) with `code > 250` and `test_code > 0` is reported and ratcheted in `docs/dev/structure-known.txt`.
- [x] A2 Add a function-size ratchet (`docs/dev/function-known.txt`) to `scripts/structure_audit.py`: any function over `FN_LIMIT = 80` lines of code not listed in `function-known.txt` (or that grew beyond its recorded line count) fails `structure_audit.py check`; `structure_audit.py seed` populates and shrinks the ratchet.
- [x] A3 Add a signature-complexity ratchet to `scripts/structure_audit.py`: count `#[allow(clippy::too_many_arguments)]` and `#[allow(clippy::type_complexity)]` per file and fail `check` if any file adds a new allow.
- [x] A4 Extend `scripts/test_structure_audit.py` with unit tests for the 350-line limit, the 250-line inline-test rule, the function ratchet, and the allow ratchet.
- [x] A5 Seed `docs/dev/structure-known.txt` and `docs/dev/function-known.txt` from the current tree so `python3 scripts/structure_audit.py check` exits `0` on `master`.
- [x] A6 Add `python3 scripts/structure_audit.py check` and `python3 scripts/omsi_uses.py --check` to `scripts/pre-commit` and to the `docs-links` job in `.github/workflows/ci.yml`.

---

## ✅ Acceptance Criteria

1. `python3 scripts/test_structure_audit.py` and `python3 scripts/structure_audit.py check` pass on `master`.
2. Introducing a new >350-line file, a >250-line production file with inline `#[cfg(test)]`, a new >80-line function, or a new `too_many_arguments` allow causes `scripts/pre-commit` and `scripts/local-ci.sh` to exit non-zero with an actionable message.
3. The pre-commit structure check completes in under 1.5 seconds.
