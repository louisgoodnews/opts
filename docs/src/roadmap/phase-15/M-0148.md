## 🎯 Objective

Extract inline `#[cfg(test)] mod tests { ... }` blocks from all **101 production files** (`crates/*/src/**/*.rs`) that exceed 250 lines of code into sibling `tests.rs` files, removing **9,274 lines of test code (~100,000 tokens)** from production source files and dropping 47 production files to ≤ 250 code lines (and 39 files from > 350 to ≤ 350 code lines) without splitting production logic.

---

## 📦 Deliverables & Tasks

- [ ] B1 Extract inline tests in `opts-game` (35 files > 250 code lines with inline tests) and shrink `docs/dev/structure-known.txt`.
- [ ] B2 Extract inline tests in `opts-bevy` (23 files) and `opts-gui` (18 files) and shrink `docs/dev/structure-known.txt`.
- [ ] B3 Extract inline tests in `opts-omsi` (8 files), `opts-sim` (6 files), `opts-benchmark` (6 files), `opts-hardware` (2 files), `opts-cli` (1 file), `opts-traffic` (1 file), and `opts-types` (1 file).
- [ ] B4 Verify every extracted `tests.rs` starts with a `//!` module doc comment and that the workspace `#[test]` multiset is unchanged.

---

## ✅ Acceptance Criteria

1. Zero production files over 250 lines of code contain an inline `#[cfg(test)]` module (`f.code > 250 and f.test_code > 0` count is 0).
2. `docs/dev/structure-known.txt` is re-seeded and shrinks by at least 39 entries.
3. `./scripts/local-ci.sh` passes with identical test counts before and after.
