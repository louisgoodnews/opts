## 🎯 Objective

Raise the share of keyed `.o3d` meshes that render correctly and remove the loading stalls the decoder causes. Decode asynchronously, make the decoder deterministic and parameterised, bound the on-disk cache, and keep investigating the generator's state chain (`q = n·s mod 8000`) with the twin corpus.

---

## 🔍 Scope

**In Scope:**
- Move `decode_confident` onto `AsyncComputeTaskPool` (or a pre-warm stage in the loading pipeline) so tile loading never blocks (F-003).
- Replace environment lookups in `descramble.rs` with a `DecodeParams` struct; environment parsing stays in examples (F-014).
- Cache policy: size cap/LRU and a version derived from the decoder parameters (F-017).
- Research task: reproduce the state chain from the twins; success criterion is exact decoding of ≥ 99 % of twin meshes. Record every negative result in `docs/src/formats/binary/o3d.md`.
- Report decoded/skipped counts in the F10 overlay and `WorldStats`.

**Out of Scope:**
- Using OMSI executables to learn the scheme (forbidden by ADR-0002).
