## 🎯 Objective

Placed scenery objects and splines make their sounds: street lamps hum, traffic lights tick, fountains run, rails and roads carry their ambience, all from the data of the installation and heard through the sound engine with the right range, loudness and bus (Ambient).

---

## 📦 Deliverables & Tasks
- [x] Docs first (done: [sound_cfg](../../formats/text/vehicles/sound_cfg.md) "Sound configurations of scenery objects"; no spline names a sound): the `[sound]` key of `.sco` (and the sound references of `.sli`) with a corpus census: how many objects and splines name a sound file or a sound `.cfg`, with which `[sound]`/`[loopsound]`/`[3d]` blocks (the 275 scenery WAV files, 3.6 GB; the file case-insensitivity of the lookup); mark what is unverified ❓ (Q-AU01: OMSI's own distance fall-off).
- [x] Parse the referenced sound configuration (`opts_core::formats::sound`, corpus test over 300 files) (`opts_core` has the format page [sound_cfg](../../formats/text/vehicles/sound_cfg.md)) into emitter definitions: clip, loop or one-shot, `[3d]` position and distance, volume curve, the script variable that drives it.
- [x] Place the voices when an object is built (`scenery_sound::attach`; editor-only sound helpers included); decode worker threads (`ClipLoader`); a memory limit/eviction is open (tile streaming), and remove them with the tile; a decode worker thread and a memory limit for the clip cache (the engine's `ClipCache` decodes on the calling thread today).
- [~] Triggers from the objects' scripts and volume curves over the session clock done; the objects' own script variables in `[volcurve]` and `[conditionSingle]` open (the scenery runtime, M-0045) to `gain` and `speed`; objects without script variables play as authored.
- [x] Spline sounds: none exist in the data (0 of 16,878 `.sli`); road and rail noise is a vehicle matter (Q-AU04). Original task text: sound sources along a spline (rolling noise of rails, road surface) placed at the stations nearest to the listener, not one per segment.
- [x] Protocol (`audio.state.scenery` and `.clips`, 1.19.0): `audio.state` lists the world's emitters by object; a screenshot-style recipe for a lamp, a signal and a fountain.

---

## ✅ Acceptance Criteria
1. The census page lists every sound reference of objects and splines with counts.
2. On a map with lamps, signals and a fountain, `audio.state` shows their emitters near the camera with levels that fall with distance, none beyond their range, and the voice budget respected; the system mixer shows the game's stream playing.
3. Tile unloading removes the emitters; memory stays bounded.
4. `./scripts/local-ci.sh` passes; no OMSI asset committed.
