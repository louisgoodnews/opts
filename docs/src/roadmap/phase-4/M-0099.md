## 🎯 Objective

Buses know their line, course, destination and stops: the `.hof` data and the timetable are parsed and served to the scripts through the route and timetable callbacks, and the player can select line and destination.

---

## 🔍 Scope

**In scope:** `.hof` parser, route and timetable model, 25 callbacks, line and destination selection, the IBIS-related variables.

**Out of scope:** Script textures (M-0100), scheduled AI buses (M-0049 phase 2), ticketing (M-0101).

---

## 📦 Deliverables & Tasks

- [x] `opts_core::formats::hof` parser for the 27,729 `.hof` files (CP1252, UTF-8, UTF-16LE), with a corpus test (`hof_corpus.rs`: all 27,779 files parse).
- [x] Timetable files (`.ttl/.ttp/.ttr`, `Busstops.cfg`, `StnLinks.cfg`: parsed, linked to the stop list, the distance along a run from the links; 7,307 links, 1,970 of 1,981 bus trips fully linked) and the model of the active timetable: current stop, arrival and departure times (seconds of day), terminus, line string, delay against the simulation clock.
- [x] Real implementations of `GetTerminusString`, `GetTerminusIndex`, `GetTerminusCode`, `GetBusstopString`, `GetBusstopIndex`, `GetBusstopCount`, `GetRouteIndex`, `GetRouteBusstopIdent`, `GetRouteTerminusIndex`, `GetDepotStringGlobal`, all `GetTT*` (the signatures of the callbacks reference).
- [x] Line and destination selection: the *Line and destination* page of the vehicle menu (Left Alt, search over the depot's routes, the map's timetables as line file, tour and run) and control-protocol commands (`bus.set_route`, `bus.get_route`); the variables `target_index_int`, `schedule_active`, `Refresh_Strings`, `AI_Target_Index`, and the strings `number`, `yard`, `act_busstop`, `SetLineTo`, `ident`.
- [x] Docs: `hof.md` and `callbacks.md` updated with the verified semantics.

## ✅ Acceptance Criteria

1. For NG272 (reference), SD200 and HH109, checked in the rig first: selecting a line and course sets, in the scripts' own string variables, exactly the strings the hof defines for that course; 0 route or timetable callback stubs remain for these vehicles.
2. Corpus: all `.hof` files of the installation parse; the report shows the number of stubbed route callbacks over the 1,089 buses falling by at least 90 %.
3. `GetTTDelay` follows the simulation clock; times wrap at 24 h. *(Met: the delay is the clock minus the arrival at the current stop, wrapped to within 12 h; tests `the_delay_is_the_clock_minus_the_arrival_at_the_current_stop` and `the_delay_wraps_at_midnight`.)*

All gates pass (`cargo fmt`, `cargo clippy -D warnings`, `cargo test --workspace --all-features`, `./scripts/local-ci.sh`); no unsafe code; no OMSI asset committed.

---

## ⚠️ Risks

- The meaning of some string columns is partly inferred: keep the column tables in `hof.md` the single source.
- Timetable semantics for unscheduled player driving: free-drive vehicles get an empty timetable that returns neutral values, never garbage.
