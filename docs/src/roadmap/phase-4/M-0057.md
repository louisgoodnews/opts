## 🎯 Objective

Vehicle scripts call the host with `(M.V.name)` for data they cannot know. Without these callbacks the IBIS stays logged out, the matrix displays and the cabin monitors stay empty (the text-texture pipeline of 2026-10-12 draws whatever string variable the scripts fill; they fill nothing without a timetable).

## 📦 Deliverables

- [x] `ExternalHandler` returns whether it handled a callback; unhandled ones are reported once (`opts_bevy::host_callbacks`).
- [x] `NrSpecRandom` (a number in [0, 1) fixed per vehicle and argument; used for door speeds and the like).
- [ ] **Hof file parser** (`Vehicles/<bus>/*.hof`, `Aachen.hof`, …: the depot's termini, routes and bus-stop strings) in `opts-core`, documented in `docs/src/formats/`.
- [ ] Terminus callbacks: `GetTerminusIndex(code)`, `GetTerminusString(index, field)`, `GetTerminusCode(index)`; route callbacks: `GetRouteIndex`, `GetRouteBusstopIdent`, `GetRouteTerminusIndex`; bus-stop callbacks: `GetBusstopIndex/String/Count`. Argument conventions are inferred from the scripts (e.g. `(L.L.IBIS_TerminusIndex) 5 (M.V.GetTerminusString)`), recorded in `predefined-variables.md` as they are verified.
- [ ] Timetable callbacks of the running schedule: `GetTTLineString`, `GetTTTerminusIndex`, `GetTTBusstopCount/Index/Name/Dep/Arr`, `GetTTDelay`; the schedule comes from the chosen line and tour of the new-game screen (`.ttl`/`.ttp`, [timetables](../../formats/map/timetables.md)); `schedule_active` and the predefined strings `Yard`, `SetLineTo`, `Number`, `Ident` are set at start.
- [ ] Depot strings (`GetDepotStringGlobal`), tickets (`GetTicketName/Value`, `GiveChangeCoin`) from the ticket pack (`.otp`), passengers (`GetHumanCountOnSeat/PathLink`), `GetHeightAbovePoint`.
- [ ] Announcements: `(T.F.ev_IBIS_Ansagen)` with the file name from the string stack, to the audio layer (M-0027).

**Acceptance:** on Aachen, a bus started on line 33 shows line number and destination on its matrix displays and the stop names on the cabin monitor; the corpus run (`vehicle_scripts`) reports no unimplemented callback for the NLC, SD200 and O530 families.
