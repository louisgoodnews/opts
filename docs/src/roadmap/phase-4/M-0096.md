## 🎯 Objective

Make every bus load and run its scripts with defined behaviour and make the state of the integration measurable: a headless rig with an integration report, a generated input table with a complete feed, and a signature-correct stub for every engine callback.

---

## 🔍 Scope

**In scope:** The `script_rig` example and the integration report; the typed callback registry (39 callbacks) with stack-correct stubs; the machine-readable input table and complete feed; the contract-bug fixes found by the audit; per-vehicle diagnostics.

**Out of scope:** Real implementations of any callback (P3-P5), the physics contract (P1), consist state (P2).

---

## 📦 Deliverables & Tasks

- [~] `script_rig` (`opts-bevy/examples`, since the real host callbacks live there; done 2026-10-18 except golden runs and a CSV profile format): scripted input profile (pedals, speed ramp, door requests), CSV of all variables, corpus mode with a JSON **integration report** per bus (unfed inputs, unconsumed outputs, callbacks stubbed vs real, stack underflow sites, diagnostics, instructions per frame).
- [x] `CallbackRegistry` in `opts-sim` (done 2026-10-18: `opts_sim::script::callbacks`, 45 signatures, `apply_stub`, `callback_stats`; the contract test per signature): with the signatures of the [callbacks reference](../../formats/text/vehicles/callbacks.md); a stub pops its arguments, pushes neutral results (`0` / empty string) and logs one `ERROR` per vehicle, script and callback; unregistered names keep today's behaviour plus an `ERROR`.
- [~] `opts-sim/src/script/inputs.rs` (table, feed plan and output table compiled and tested 2026-10-18, used by the rig; the game's feed does not use it yet): the predefined variables as a table (name, unit, source); `feed_predefined` generated from it; date, time, weather, `PrecipRate/Type`, `SunAlt`, `Pause`, `AutoClutch`, `Clutch`, `StreetCond`, `Envir_Brightness`, `kmcounter_*`, `schedule_active`, `coll_*` (zeros until a collision source exists); unfed names logged once per vehicle.
- [ ] Repaint `[setvar]` variables of the selected livery applied before `{init}` for every vehicle.
- [ ] Contract fixes: a script that writes `Throttle`/`Brake`/`AI`/`AI_Engine` keeps its value (host writes only when `engine.writes(name)` is false); `script_startup_system` ordered before `vehicle_script_system`; scripts run only for the player's consist and vehicles within the scripting radius; `GetTime` precision; `seed_random` per vehicle from a stable vehicle id; `NrSpecRandom` seed independent of entity bits; every compile warning and error of a vehicle's scripts logged once with file and line.
- [~] Tests: `feed_predefined` (the feed tests of `inputs.rs`) and one contract test per callback signature are done; startup ordering is not.
- [ ] **The rig is the verification surface and CI substrate of the whole programme** (decided 2026-10-14): its profile format, golden runs and integration report are designed so that the acceptance criteria of M-0097 to M-0103 can be checked in the rig before anything is verified in the game window; the reference vehicle is the MAN NG272 (GN92).
- [ ] Docs: `script-vm.md` and `predefined-variables.md` updated, the route document's state table corrected, the integration report summary committed.

---

## ✅ Acceptance Criteria

1. Corpus run over all 1,089 player buses: 0 stack-underflow sites at callback calls, 0 NaN or infinite outputs over 600 frames, every unfed input name listed in the report.
2. A script-written pedal reaches the physics; two vehicles with different ids produce different `random` initial states and the same id the same state.
3. All unit and contract tests pass; `./scripts/local-ci.sh` passes; the report is reproducible with one command.

All gates pass (`cargo fmt`, `cargo clippy -D warnings`, `cargo test --workspace --all-features`, `./scripts/local-ci.sh`); no unsafe code; no OMSI asset committed.

---

## ⚠️ Risks

- The input table must not hide bugs by feeding zeros: unfed-but-declared names stay visible in the report.
- Fixing pedal ownership changes the behaviour of scripts that write pedals: re-run the golden profiles.
