## 🎯 Objective

Generate high-performance, seamless 3D terrain meshes and animated water surfaces from parsed binary `.map.terrain` and `.map.water` grid files. Implement terrain tessellation in `opts-bevy` converting OMSI's regular elevation grid into indexed triangle strip meshes with smoothed vertex normals, UV texture mapping, multi-layer ground texture splatting, and physical ground elevation queries for vehicle wheel raycasting.

---

## 🔍 Scope

**In Scope:**
- **Phase A — Architecture Specification:**
  - Author `docs/src/architecture/terrain-rendering.md` specifying vertex layout, normal smoothing across tile edges, ground material texture arrays, and elevation sampling APIs.
- **Phase B — Mesh Generation & Material Systems (`opts-bevy`):**
  - Implement `generate_terrain_mesh`: Construct Bevy `Mesh` from elevation matrix, calculating smooth surface normals and tangents.
  - Implement terrain multi-texture material support (blending multiple ground textures via vertex alpha / splatmaps).
  - Implement `generate_water_mesh`: Construct planar water polygons at tile-defined water levels with gentle wave vertex displacement and translucency.
  - Implement `GroundElevationQuery` resource/system providing $O(1)$ bilinear height and surface normal queries at arbitrary $(X, Y)$ world coordinates for physics raycasting.
- **Phase C — Testing & Visual Verification:**
  - Unit tests verifying exact height interpolation and normal generation on synthetic elevation matrices.
  - Integration test verifying elevation matching across adjacent tile boundaries.
  - Interactive example `examples/render_terrain.rs` displaying a multi-tile terrain section with water planes and wireframe toggle.

**Out of Scope:**
- Runtime procedural terrain deformation or dynamic digging.
- Dynamic spline road intersection Boolean CSG mesh carving.
