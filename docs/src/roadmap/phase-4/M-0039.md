## 🎯 Objective

Render the text that OMSI draws onto object textures: street and stop signs, departure boards and destination displays. The `.sco` parser already exposes `ScoTextTexture` (fixed string variable, named variable or runtime texture reference); no renderer consumes it, so these objects show as white quads.

---

## 🔍 Scope

**In Scope:**
- Specify the rendering rules in `docs/src/architecture/text-textures.md`: font lookup, size, colour, alignment, string-variable resolution, per-instance `string_vars` from the tile.
- Rasterise text into an `Image` per object instance and bind it to the material slot named by the `.sco`.
- Resolve runtime texture references (`\S:n`, `Textfeld_*`) instead of ignoring them.
- Cache by (font, text, size) to avoid per-frame work; update when a script variable changes (after M-0026).

**Out of Scope:**
- Script-driven dynamic text before the VM exists (M-0026).
