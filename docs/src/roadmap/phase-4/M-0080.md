## 🎯 Objective

The user controls how much of the map is resident: either **everything** (*Load all tiles on start*) or a **radius of tiles around the centre tile** (the tile the player camera stands on), with a default that adapts to the machine.

## 📦 Deliverables & Tasks
- [x] **Setting `Load all tiles on start`** (`gameplay.load_all_tiles`, bool, default off): all map tiles are force-loaded during loading and **kept resident** (no eviction, no streaming-out) for the whole session. Registered in the settings registry (generated reference, control protocol `settings.*`).
- [ ] **Exposed in the *Plan a drive* summary** (Review step, [wizard](../phase-9/wizard-and-loading.md)): the same setting as a visible switch with a plain-language note (loading time and memory use; an estimate from the tile count and the hardware profile, e.g. 'about 2.1 GB, 40 s'); changing it there changes the global setting (or offers *only for this drive* — decision recorded in the milestone); the loading screen shows real progress per tile.
- [x] **Setting `Tile radius`** (`gameplay.tile_radius`, integer ≥ 1, step 1, max from the map size): number of tiles loaded around the centre tile (1 = 3×3, 2 = 5×5, …); applies live (streaming adjusts without restart). Disabled with the reason when *Load all tiles* is on.
- [x] **Dynamic default:** when the user has not chosen a value, the radius is derived from the hardware profile of `opts-hardware` (GPU class and VRAM, free system memory, CPU threads, storage speed class) through a documented, tested function (`recommended_tile_radius(&HardwareProfile, &MapStats)`); the settings page shows 'Automatic (currently 3)' and a *Reset to automatic*.
- [ ] Memory guard: when *Load all tiles* would exceed a safe share of available memory the UI warns (red text per the UI standards) and offers the radius mode; never silently crash or swap.
- [x] Streaming uses hysteresis so the radius does not thrash at tile borders (existing paging rules kept).
- [x] Control protocol: `settings.*` cover both; `scene.tiles` reports loaded/resident tiles, radius and mode.
- [x] Docs: update `docs/src/architecture/` streaming page and the settings reference; tests for radius math, force-load retention, live change, wizard exposure.

## ✅ Acceptance Criteria
- With *Load all tiles* on, every tile of a test map is resident after loading and stays resident while the camera moves across the map (test and control-protocol check); with it off, only the radius around the centre tile is resident.
- The default radius differs between two synthetic hardware profiles (test) and is explained in the UI; the summary screen shows and changes the all-tiles switch.
