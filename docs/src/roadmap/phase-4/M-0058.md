## 🎯 Objective

Text textures (`[texttexture]`, done for vehicles 2026-10-12) draw one string with one font. Script textures are drawn by the scripts themselves with the `ST*` callbacks and cover the dash TFTs, tachographs, ticket printers and IBIS screens.

## 📦 Deliverables

- [ ] `[scripttexture]` declarations (width, height) of `model.cfg` bound to meshes with `[useScriptTexture]`; one CPU canvas per texture, uploaded when the script unlocks it.
- [ ] Callbacks: `STLock`, `STUnlock`, `STFilter`, `STSetColor`, `STDrawRect`, `STTextOut`, `GetFontIndex`, `TextLength` and the remaining ones of the "script texture" list (17 in all, [predefined variables](../../formats/text/vehicles/predefined-variables.md)); fonts from `Fonts/*.oft` (the registry of `text_texture`).
- [ ] The drawing layer works on a canvas trait so the visual script editor (M-0056) can preview a texture without Bevy.
- [ ] Argument conventions verified against the scripts and recorded in `predefined-variables.md`.

**Acceptance:** the dash display of the NLC (`MAN_Cockpit.osc`) and the ticket printer show their text; no `ST*` callback is reported as unimplemented for the NLC, SD200 and O530 families.
