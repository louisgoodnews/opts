## 🎯 Objective

Make regressions of the kind found in this audit impossible to merge: link checking and an mdBook build in CI, a pinned toolchain, a Windows build, warning-free docs, dependency hygiene, and automated coverage for the F1 key path.

---

## 🔍 Scope

**In Scope:**
- Add `mdbook build` and a link-check job to `.github/workflows/ci.yml`.
- Add `rust-toolchain.toml`, `.editorconfig` and `deny.toml`; upgrade or replace `binrw 0.13.4` (future-incompatibility warning).
- Add a Windows matrix entry (`x86_64-pc-windows-msvc`) for `cargo check` and tests.
- Run `RUSTDOCFLAGS=-D warnings cargo doc` in CI.
- Run the F1 reporting keyboard checklist once, record the result, and add a headless key-event test for the F1 toggle (F-026).

**Out of Scope:**
- Release packaging (M-0034).
