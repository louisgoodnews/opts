## 🎯 Objective

Move the workspace from Bevy 0.14.2 to a current release in verified steps. About 35,000 lines touch Bevy; the UI layer (`NodeBundle` ×201, `Style` ×449, `TextBundle` ×186, `ButtonBundle` ×63), events (`EventReader/Writer` ×80), screenshots (`ScreenshotManager`), the `ExtendedMaterial` ground shader and bundle-based spawning change in every release since 0.15. `bevy_remote` (0.15+) could replace the shallow introspection of M-0043.

---

## 🔍 Scope

**In Scope:**
- Migrate one minor version at a time (0.15 → 0.16 → …), keeping `cargo test` and a reference screenshot set green after each step.
- Re-implement the layered ground shader (WGSL imports and `AsBindGroup` changed) and the sky dome on the new render API.
- Replace bundle spawning by required components; replace the removed screenshot manager in reporting.
- Evaluate `bevy_remote` as the backend of `entity.*`/`resource.*` in the control protocol.
- Out of scope: new features during the migration.
