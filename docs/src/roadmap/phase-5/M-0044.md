## 🎯 Objective

Move the workspace from Bevy 0.14.2 to a current release in verified steps. About 35,000 lines touch Bevy; the UI layer (`NodeBundle` ×201, `Style` ×449, `TextBundle` ×186, `ButtonBundle` ×63), events (`EventReader/Writer` ×80), screenshots (`ScreenshotManager`), the `ExtendedMaterial` ground shader and bundle-based spawning change in every release since 0.15. `bevy_remote` (0.15+) could replace the shallow introspection of M-0043.

---

## 📝 Migration notes (2026-10-11, 0.14.2 → 0.19.1)

Done in one jump instead of stepwise (the 0.19 sources were in the cargo registry; compile errors led the way). Mechanical parts went through `scripts/migration/bevy019_ui.py` (kept for reference), the rest by hand.

| Area | Change |
| :--- | :--- |
| Dependencies | `bevy 0.19` (`glam` 0.32 with it), `bevy_asset_loader` dropped (unused). |
| UI | `Style` → `Node`; `NodeBundle`/`ButtonBundle`/`ImageBundle`/`TextBundle` → component tuples; `TextStyle` → `TextFont` (`FontSize::Px`) + `TextColor`; `Text.sections` → `Text` + `TextSpan` children (the text area now uses a root text and two spans); `BorderColor::all`; `border_radius` is a `Node` field; `ZIndex::Global` → `GlobalZIndex`; `ComputedNode` for sizes; fonts via `Font::from_bytes` and `FontSource::Handle`. The 3D cameras carry `IsDefaultUiCamera` (with the deactivated menu camera around, the HUD otherwise did not draw). |
| Events | `Event`/`EventWriter`/`EventReader`/`add_event` → `Message`/`MessageWriter`/`MessageReader`/`add_message`; `ManualEventReader` → `MessageCursor`. |
| Hierarchy and spawning | `PbrBundle`, `MaterialMeshBundle`, `SpatialBundle`, light and camera bundles → `Mesh3d` + `MeshMaterial3d` + `Transform` etc.; `Parent` → `ChildOf`; `push_children` → `add_children`; `despawn_recursive` → `despawn`; `Commands::add` → `queue`; `get_single` → `single`. |
| Assets | `AssetLoader::load(&self, &mut dyn Reader, …)`, loaders need `TypePath`; `Image::data` is `Option<Vec<u8>>`; modules moved (`bevy::image`, `bevy::mesh`, `bevy::light`, `bevy::camera`, `bevy::shader`, `bevy::asset::RenderAssetUsages`); `uuid_handle!` replaces `weak_from_u128`. |
| Render | The material bind group is `@group(#{MATERIAL_BIND_GROUP})` (3), not 2: the layered ground shader had to follow; `ScreenshotManager` → `Screenshot` entity with an observer (`ScreenshotCaptured`); `AmbientLight` resource → `GlobalAmbientLight`; `TransformSystems`/`InputSystems`; `shadows_enabled` → `shadow_maps_enabled`; non-send resources `init_non_send`. |
| Window | `WindowResolution::new`, cursor options in the `CursorOptions` component, `BorderlessFullscreen(MonitorSelection)`. |

Also: the dev profile no longer builds full debug info (`line-tables-only`, none for dependencies); with Bevy the test and example binaries had grown `target/debug` to 659 GB.
