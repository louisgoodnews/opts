## 🎯 Objective

OPTS can **keep track of which mesh is placed where** — tile, source record, file, position, materials, decode quality — and **report it into the run log and through the control protocol**, in an opt-in debug mode (setting or command line). A defect seen in a screenshot becomes an asset reference in one call, for humans and for AI agents.

## 📦 Deliverables & Tasks
- [ ] **Design page** `docs/src/architecture/scene-trace.md`: record schema, modes, cost, privacy (paths are relative to the OMSI folder; no user names), output formats, how it relates to the content issue registry, the mesh issue registry and the UV incident files.
- [ ] **Trace record per placed thing** (scenery object, spline segment/attachment, terrain tile mesh, parked/AI/session vehicle and its parts, humans): tile id and tile file, record index in the `.map`, kind, source file (`.sco`/`.o3d`/`.x`/`.bus`), part and LOD, world position/rotation/scale, material and texture references, ECS entity, decode stage and `UvQuality`, load warnings, time of loading.
- [ ] **Modes:** `off` (default, zero cost: no allocation, no per-object work), `summary` (counts per tile and kind, issues only), `full` (every record); filters by tile, radius around the camera, kind, file pattern; enabled by *Settings → Advanced → Developer tools → Scene trace*, by the command line flag `--trace-scene[=summary|full]`, and by the protocol (`trace.set`).
- [ ] **Log output:** JSON Lines per run next to the other run logs (rotated, size-capped, with a header record naming build, map and mode); the human log gets one-line summaries.
- [ ] **Query by view:** control protocol `trace.pick` (what is under the screen point or the crosshair: the full record plus parents), `trace.tile`, `trace.find` (by file or kind), `trace.region`, `trace.export`; works with screenshots (`snapshot` + `trace.pick` at a pixel).
- [ ] **In-world overlay (developer panel):** labels or colour-coding by kind/decode quality, highlight the picked object; off by default.
- [ ] **Docs for agents:** recipe 'screenshot defect → asset reference' and the link to issue registries; tests: record completeness for a synthetic map, zero-cost-when-off check, filters, JSONL schema, pick.

## ✅ Acceptance Criteria
- With the mode on, a run on a test map writes a JSONL file where every placed object has a record; `trace.pick` at a pixel returns the mesh file and tile; with the mode off no trace allocation happens (test) and frame time is unchanged within noise.
- The mesh-audit workflow can map each screenshot defect to a source file without manual search.
