## 🎯 Objective

Bring the workspace back under the standards in `docs/src/contributing/standards.md`: files ≤ 500 lines, functions ≤ 80 lines, no panicking calls in library code, no stubs, warning-free rustdoc.

---

## 🔍 Scope

**In Scope:**
- Split `omsi_world.rs` (tiles, objects, splines, vehicle loading, debug overlay), `sco.rs::from_text` (per keyword family), `opts-catalogue/src/lib.rs`, `descramble.rs` and the 250–420-line UI builders.
- Group system parameters into `SystemParam` structs and remove the lint allows where possible.
- Move `catalogue_service::testing` behind a `test-support` feature (F-005); replace the remaining `unwrap`/`expect` calls (`x/parse.rs:410`, `human.rs:213`, `opts-catalogue/lib.rs:191`).
- Implement or remove the Load Game and Credits stub screens and the `opts-tools` placeholder binary.
- Fix the six rustdoc warnings; enforce `cargo doc -D warnings` in CI (with M-0042).

**Out of Scope:**
- Behavioural changes; every split is a pure refactor with unchanged tests.
