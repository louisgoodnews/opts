## 🎯 Objective

Prove that the battery switch turns every electrical output off, and find out whether the four HH109 `cockpit.osc` files lose the off branch to an unbalanced `{if}`.

## 🧩 Scope

1. Script-rig test: press and release the battery toggle; assert the main busbar variable is zero.
2. Name the real battery trigger names in the M-0123 card. The card's `cp_batterietrennschalter_off` matches nothing in code; the code produces `cp_batterietrennschalter_toggle_off` and `kw_batterietrennschalter_off`.
3. Check the four files against the parser. The OMSI files are not edited; record each result in the content issue registry.

## ✅ Acceptance Criteria

1. The rig test passes on master and fails when the off branch is removed.
2. The four files are checked, and each has a registry line with its result.
3. The M-0123 card names the real triggers.

## ⚠️ Risks

- The OMSI installation is read-only for OPTS; the fix for a broken script is recorded, not applied.
