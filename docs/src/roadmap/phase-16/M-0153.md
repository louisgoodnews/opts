## 🎯 Objective

A passenger can ask for a stop. The stop request light and the passenger stop button state follow the manual, and the rear-door and stop-brake interlocks run through the vehicle scripts and are tested.

## 🧩 Scope

1. Stop request state per stop, set by a waiting or riding passenger and cleared when the bus stops there.
2. Cabin request light and stop button: the script variable names are read from the vehicle scripts (prose only; no copying).
3. Alighting follows the request (links to [M-0154](M-0154.md)).
4. A test of the request flow, and a check that rear doors open only as the scripts allow.

## ✅ Acceptance Criteria

1. The request light is lit after a request and cleared at the stop.
2. The request flow has a unit test that fails when the request handling is removed.
3. Dated in-game check at one stop with a request.

## ⚠️ Risks

- The script variable names must be confirmed from the vehicle scripts, not assumed.
- Changes alighting, so M-0101 tests must be re-run.
