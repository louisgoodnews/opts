## 🎯 Objective

Choose the timetable circuit by day type (weekday, weekend, holiday where the data has it) and by time of day, as OMSI does, so that night lines run only at night.

## 🧩 Scope

1. Read the day-type and circuit data from the map's timetable files (`TTData`); document the fields used, in prose.
2. Circuit selection in the timetable run for the current in-game date and time.
3. Passenger weights by day type (passengers.md §4 says they are not applied today) if the data gives them.

## ✅ Acceptance Criteria

1. A test with a sample `TTData` that has two day types selects the right circuit for each.
2. A night-only line is absent in the day and present at night, in a dated run.
3. [Passengers](../../simulation/passengers.md) §4 and the timetable doc state the rule.

## ⚠️ Risks

- Some maps may lack calendar data; the fallback must be stated.
