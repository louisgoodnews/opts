## 🎯 Objective
Document the engine-side vocabulary of the script system and the way real vehicles and scenery objects organise their scripts: the predefined variables and callbacks that OMSI ships in `program/`, the standard subsystem scripts of a vehicle, the shared AI script library, and the scenery script library. Also review the shipped manuals for format facts.

> ℹ️ **Scope origin.** Proposed in [`formats/gap-analysis.md`](../../formats/gap-analysis.md) and approved by the project lead on 2026-10-04 ("Proceed"). The ROADMAP gained the item through P-002 step 4.

## 🔍 Scope
**In Scope:**
- `program/*.txt` (ten files): predefined variables, callbacks, accessor syntax, controller axes.
- Vehicle script sets (`Vehicles/*/script`, `script-g`, `script_ki`), global `Scripts/AI_Cars/`, scenery scripts (`Sceneryobjects/*/script`).
- Review of `docs/*.pdf` (manuals, quick reference) for facts about situations, drivers, tickets, destination codes, keyboard shortcuts.

**Out of Scope:**
- An interpreter or Rust code.
- Detailed per-vehicle script logic (only the architecture and conventions).

## ✅ Acceptance Criteria (Definition of Done)
1. Every variable and callback in `program/*.txt` is listed and classified; each appears in the corpus usage table (count of files using it, or "unused").
2. For the ten most common subsystem scripts the spec states the variables they own (derived from the corpus).
3. The manual review is logged with what was used and what had no format relevance.
4. Open questions (e.g. the `M.V.` accessor) are recorded.
5. Each spec follows the OPTS spec template (metadata, overview, structure, field reference, examples, Open Questions, Provenance, related documents), is linked from `SUMMARY.md` and the formats overview, and its Provenance states "No OMSI binaries were inspected".
6. `formats/gap-analysis.md` is updated to show the gap as closed (or partly closed).

## ⚠️ Risks & Mitigations
| Risk | Mitigation |
| :--- | :--- |
| The library is large (5,800 scripts). | Statistical census plus a handful of read-through samples; no per-script analysis. |
| Shipped text is copyrighted. | Paraphrase; list only facts (names, counts, parameter lists); cite the file path. |
| Meaning inferred from names may be wrong. | Mark ❓; add Open Questions; propose a mutation test where behaviour matters. |
