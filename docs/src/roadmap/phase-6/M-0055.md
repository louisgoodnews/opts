The library (and `opts-tools script` command) that derives a default script set from a vehicle specification and writes it to the export folder. See [script generator](../../architecture/script-generator.md) §4–§7, §9.

- [ ] `VehicleSpec` (serde/TOML) with defaults per class and unit-checked fields; spec schema documented.
- [ ] Generators: `main`, `engine`, `antrieb`, `bremse`, `door`, `lights`, `elec`, `articulation`, `main_ai`; constfile, varlist and stringvarlist writers; the `.bus` script block.
- [ ] **Own templates** (clean-room: no OMSI script text; names and call order only), banner and generated-region markers.
- [ ] Writer: export folder `exports/<vehicle>/Vehicles/<Name>/script/…`, never into the OMSI installation; overwrite protection with diff.
- [ ] Validator: compile, lint rules, rig checks (0–50 km/h time, service-brake deceleration, parking-brake hold, door times).
- [ ] CLI: `opts-tools script gen spec.toml --out <dir>`, `script validate <dir>`.
- [ ] Presets: city bus, articulated bus, tram; each validated and loadable in the game.

**Acceptance:** the three presets generate, validate and **drive in OPTS** (load, accelerate, brake, doors, lights) on a reference map; generated text contains no OMSI-authored script lines (policy test over the corpus: no generated line equals a corpus line longer than 40 characters).
