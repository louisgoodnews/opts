The Bevy/`opts-gui` editor on top of `opts-script_editor` and `opts-script_engine`. See [script generator](../../architecture/script-generator.md) §8.

- [ ] Plugin and standalone binary; embeds as the *Script* tab of the editor mode's vehicle workspace ([M-0051](M-0051.md) E4).
- [ ] Specification forms with units, ranges, presets, torque and brake curve editors.
- [ ] Generated-file viewer with syntax highlighting and inline diagnostics; export plan and *Export…* to the export folder.
- [ ] Live rig plots (speed, engine speed, wheel torque, brake force, doors) updating when a constant changes.
- [ ] Subsystem graph (blocks, variable pins coloured by direction, wires); custom-macro block for hand-written RPN.
- [ ] Undo/redo through the editor's command bus; autosave of the spec in the project.
- [ ] User documentation with a worked example (spec → export → drive).

**Acceptance:** an author builds a bus from a blank spec, sees the plots respond to a changed gear ratio, exports, and drives the result in OPTS without leaving the application.
