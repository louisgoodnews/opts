## 🎯 Objective

Make the emergency and service vehicles of a map (police, ambulance and similar) appear and drive on the road as the map's data says, and check which part of that data `global.cfg` controls. The traffic code already spawns these groups; this milestone finds out what is still missing: the map-level setting, the siren priority, and the behaviour near the player.

## 🧩 Scope

1. Read the map format in prose: what [global.cfg](../../formats/map/global-cfg.md) says about traffic (its keywords include `[trafficdensity_road]` and `[trafficdensity_passenger]`) and whether it has a key for roaming or service vehicles. The format page lists no such key today. If the setting is not in the format, record that, and name the file that carries the group (`ailists.cfg`, `unsched_vehgroups.txt`) instead.
2. Check the current state: [ai-traffic](../../architecture/ai-traffic.md) says every group a map lists now drives, including `Polizei`, `RTW` and `Feuerwehr` (2026-10-26). Confirm this in the game on one map, and record the groups that spawn.
3. Siren behaviour: emergency vehicles read `TrafficPriority` and `TrafficPriorityWarningNeeded`. Decide with [M-0049](../phase-4/M-0049.md) whether the priority rule is still open, and whether it belongs here or in M-0111.
4. Specify the density of these vehicles against the map's traffic curve, in the same way as the other AI groups ([density baselines](../../architecture/density-baselines.md)).

**Out of scope:** copying script or sound text from OMSI ([ADR-0002](../../adr/0002-clean-room-policy.md)); the police and ambulance response to a collision, which is [M-0171](M-0171.md).

## ✅ Acceptance Criteria

1. The format page records, in prose, whether `global.cfg` has a roaming or service setting. If it has none, the file that does control the groups is named.
2. A check on one map (in-game or by test) records which emergency groups spawn and whether they drive.
3. The siren priority rule is either done here or handed to M-0111 with a reason.
4. Any code change is in its own task and names M-0173 in its commit.
