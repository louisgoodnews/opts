## 🎯 Objective

Make the rows of the Help and Settings screens line up. Key chips and other controls of different width should not move the text beside them.

## 🧩 Scope

1. Help controls table: give the key column one sizing rule, so that every description starts at the same x position for the default key names at 1920x1080. The two spawn paths are `crates/opts-game/src/help/controls/spawn.rs` and `crates/opts-game/src/help/vehicle_controls.rs` with `vehicle_controls/widgets.rs`.
2. Settings screen: check the same rows and apply the same rule where it reads better. Record the result in ISS-055.
3. Other fixed-size controls named in the owner report: check them on the same two screens and list each one that stays as it is, with the reason.
4. Add a test that fails when the description column of the default table moves.

**Out of scope:** the Reset label's contrast on the light theme, which is [ISS-056](../../../dev/issues/ISS-056-reset-label-contrast.md) under [M-0065](../phase-9/M-0065.md); changes to the design language.

## ✅ Acceptance Criteria

1. The Help table's description column starts at the same x position in every row, for the default key names, at 1920x1080.
2. A dated screenshot path is recorded in ISS-055. Screenshots are kept out of the repository.
3. The Settings screen is checked, and either shares the rule or the reason is recorded.
