## 🎯 Objective

The brake model states that it has no ABS ([brakes.rs](../../../../crates/opts-sim/src/vehicle/brakes.rs)), and the vehicle-functions catalogue lists ABS and ASR as functions of the vehicle. Find out which script drives each aid, whether OPTS runs it, and what OPTS needs to run it, then close the gap.

## 🧩 Scope

Owner decision 2026-11-22: ABS and ASR driver aids are in scope, under this milestone.

1. Read, in prose only, the ABS and ASR parts of the vehicle scripts named in the catalogue ([vehicle functions](../../simulation/vehicle-functions.md)). Record which variables each writes and which it reads.
2. Check whether OPTS reads those variables, and whether wheel speeds are per-wheel values or derived from chassis speed.
3. If the scripts drive the aids and OPTS runs them, the gap is documentation. If the aids need per-wheel slip that OPTS does not have, the gap is a model: specify it from OPTS's own measurements and public documentation.
4. Reword the "ABS self-test" comments so that a search for ABS finds only real anti-lock code.

**Out of scope:** copying script text into the repository; an ABS model taken from OMSI internals ([ADR-0002](../../adr/0002-clean-room-policy.md)).

## ✅ Acceptance Criteria

1. The catalogue records, in prose, which script drives ABS and ASR, and whether OPTS runs it.
2. The severity (minor or major) is confirmed and recorded in [ISS-043](../../../dev/issues/ISS-043-abs-asr-driver-aids.md).
3. Any code change is in its own issue, with its own milestone entry.
