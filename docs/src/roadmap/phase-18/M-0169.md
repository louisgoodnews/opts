## 🎯 Objective

A vehicle module for a display, an on-board computer or a ticket printer can be swapped, as a mod does for a mesh or a sound. A swap changes which scripts and triggers run, so it is a different unit from the mesh and sound swaps of [M-0135](../phase-14/M-0135.md).

## 🧩 Scope

Owner decision 2026-11-22: kept separate from [M-0135](../phase-14/M-0135.md), which is not extended. This milestone is its own proposed item.

1. Define how a swapped module names its scripts and triggers, in a schema that builds on the override schema of M-0135.
2. The ticket printer part uses the ticket model of [M-0156](../phase-16/M-0156.md), so that a printer swap does not fork it.

**Out of scope:** the LOTUS module pack and its data ([ADR-0002](../../adr/0002-clean-room-policy.md)).

## ✅ Acceptance Criteria

1. The schema for a swapped module, with its scripts and triggers, is written and linked from [M-0135](../phase-14/M-0135.md).
2. A test swaps one display module and one printer module, and checks the scripts and triggers that run.
3. The printer swap uses the M-0156 ticket model (checked in review).
