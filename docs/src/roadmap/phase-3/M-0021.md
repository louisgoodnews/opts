## 🎯 Objective

Design and implement a complete Material Design 3 (M3) user interface component library in `opts-gui` built on Bevy UI. Provide the foundational design system and widgets for all OPTS menus, settings panels, vehicle pickers, timetable inspectors, in-game HUD overlays, and future editor tools. Enforce strict token consumption, zero hardcoded colors or pixel dimensions in widgets, `#![deny(unsafe_code)]`, zero bare `unwrap()` in library code, and dual-spawn ergonomics.

---

## 🔍 Scope

**In Scope:**
- **Phase A — Design Research & Specification:**
  - Complete Material Design 3 token specification in `docs/src/architecture/gui-design-system.md` covering Color (25+ roles, WCAG 2.1 AA contrast math), Typography (15 type scales), Elevation (Levels 0–5), Shape (Radius levels), Spacing (4dp/8dp grid), Motion (durations and easings), and Component blueprints.
- **Phase B — Crate Implementation (`crates/opts-gui`):**
  - Theme resource `MaterialTheme` with dynamic light/dark runtime toggling.
  - ECS design token components (`BackgroundRole`, `BorderRole`, `ForegroundRole`, `RadiusToken`, `ElevationToken`, `TypeStyleToken`) and reactive synchronization systems.
  - Layout primitives: `StackBuilder`, `RowBuilder`, `GridBuilder`.
  - Core Tier 1 widgets: `ButtonBuilder` (6 variants, reactive `on_click` actions), `LabelBuilder`, `IconBuilder`, `CardBuilder` (3 variants), `DividerBuilder` (horizontal/vertical), `TextFieldBuilder` (outlined/filled, focus management).
  - Form & Selection widgets: `CheckboxBuilder` (tristate), `SwitchBuilder` (pill track/thumb), `RadioBuilder` (group mutual exclusion with `ParamSet`).
  - Advanced Desktop & Simulation widgets: `ComboboxBuilder` (dropdown menu), `NotebookBuilder` (tab bar and panel switcher), `ToastBuilder` (floating timed notification), `ToplevelBuilder` (floating modal dialog with title bar and scrim), `TreeviewBuilder` & `TreeNode` (hierarchical tree navigation), `DateSelectBuilder` & `DateTimeSelectBuilder` (calendar and schedule selectors).
  - Interaction and focus navigation system (`Focusable`, `FocusEvent`, `FocusPlugin` with `Tab` / `Shift+Tab` cycles).
  - Semantic event streams for all interactive widgets.
  - Dual-spawning pattern (`spawn(&mut Commands)` and `spawn_child(&mut ChildBuilder)`) for all builders.
  - Interactive gallery application (`examples/gallery.rs`) and sub-demos (`examples/buttons_and_text.rs`, `examples/layout_demo.rs`).
  - Crate documentation in `docs/crates/opts-gui.md` and `docs/crates/opts-gui/README.md`.

**Out of Scope:**
- Direct coupling to simulation state or vehicle telemetry (handled via events in Phase 4).
- Editor-only tooling windows (belongs in Phase 5).
