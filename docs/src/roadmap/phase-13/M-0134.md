## 🎯 Objective

`opts-model` holds the native schema (stubs that compile, `serde` derives), the importer location is settled, the rest of the workspace uses the new crate names, and the documents state the boundary rules. Merged to `master` with `--no-ff` after the project lead's approval.

**Rules fixed by the task (all milestones of the phase):** no circular dependency (shared domain types sit in a lower crate that both parsers use); `opts-sim`, `opts-bevy` and `opts-game` must not depend on `opts-omsi`; `opts-omsi` is a leaf adapter used by the importer; parser behaviour does not change (tests pass identically before and after); no OMSI parsing logic is deleted; files move with `git mv` so `git log --follow` works; no new workspace dependency without approval; nothing reaches `master` without the project lead's approval; checkpoints after phases A and B.
