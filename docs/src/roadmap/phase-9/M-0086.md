## 🎯 Objective

Long dropdowns (the 16 start points of a map, language lists) are **searchable and scrollable**, and the catalogue summary in *Settings → Content* states what it counts.

## 📦 Deliverables & Tasks
- [ ] **Scrolling** of the combobox menu (wheel, keyboard focus, scroll bar) — fixed on `fix/dropdown-scroll` (R-28).
- [ ] **Search in dropdowns:** when a menu has more than N options (default 8) a search field at the top filters the options as the user types (case- and diacritics-insensitive, 150 ms debounce), keeps the selection if still visible, supports arrow keys and Enter, shows 'No match' and a clear button; opening focuses the field; short lists stay plain; localised placeholder ('Search…'); accessible name; works with the control protocol (`ui.text` into the search field, `ui.select`).
- [ ] Test: filter, keyboard flow, selection retained, 16-option wizard start-point list; golden/a11y matrix unchanged for short lists.
- [ ] **Catalogue count (R-24):** *Settings → Content* said '75313 Karten, Fahrzeuge und weitere Inhalte gefunden' next to 'Home: 43 maps · 947 vehicles'; the number is the total of catalogue entities of every kind (scenery objects, splines, textures, sounds, humans, …), not maps. Show a breakdown by kind (maps, vehicles, scenery objects, splines, other) from the catalogue, explain 'files' versus 'entries', and keep both numbers consistent with Home (German and English strings).

## ✅ Acceptance Criteria
- A dropdown with 16 entries can be filtered by typing and scrolled; the Content page shows maps and vehicles separately with the same numbers as Home.
