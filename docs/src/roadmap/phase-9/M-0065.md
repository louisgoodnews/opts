## 🎯 Objective

Make the interface usable by more people and prove it with people.

## 📦 Deliverables & Tasks
- [x] **WCAG 2.2 AA audit** of all screens and themes (checklist and findings table: [accessibility audit](accessibility-audit.md)); fixes; High-contrast theme verified; colour-blind simulation in the contrast test. *Automatic part only: the HUD, loading screen and report dialog are not in the matrix.*
- [x] Reduced motion and flashing limits verified; UI scale 75–200 % verified at three window sizes without clipping (scrolling replaces clipping where a page is taller than the window).
- [x] **Gamepad and wheel navigation** of every menu on the action layer; documented device profiles ([input devices](../../reference/input-devices.md)). *Synthetic input only; no hardware; `Help`/`Menu` actions unconsumed.*
- [x] Screen-reader feasibility: **decision: use Bevy's accessibility support** (`AccessibilityNode` written from one place, name/role/state tested in `en` and `de`); announcement by a real screen reader is **unverified** (open, owner: project lead).
- [x] **German and English complete**, pseudo-locale and long-string tests passing; language selectable at first run and in Settings; documented process for community translations ([translating](../../reference/translating.md); *loading packs from the user directory: [M-0083](M-0083.md)*).
- [ ] **Usability test** (protocol: [usability-test-protocol](../../meta/usability-test-protocol.md), **written; no session held**): a moderated protocol (5 participants, 6 tasks: first start, plan and start a drive, change a setting, find controls, report a problem, leave a drive; measures: success, time, errors, perceived effort, HUD glance times) with a results report in `docs/src/meta/` and a list of resulting fixes.
- [x] Golden screenshots (software painter, fixture content), CI rules green across the shell screens. *UI performance budget (1 ms, 1,000-item list) is not measured here; HUD and loading screen are not in the rules matrix.*

## ✅ Acceptance Criteria
- AA findings table has no open 🔴; all keyboard and gamepad traversals pass.
- ≥ 4 of 5 participants complete every task without help; failures are logged as findings.
- The report's rules that the tests could not cover are listed as open items with owners.
