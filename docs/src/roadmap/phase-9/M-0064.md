## 🎯 Objective

A driving-safe HUD built from registered widgets, with help, hints and feedback that fit the moment.

## 📦 Deliverables & Tasks
- [x] Instrument token set with day/night variants (M-0061); instrument cluster (speed, gear, brake state, units from *Settings → Interface*; RPM hidden until the simulation provides it, not "--").
- [x] `HudWidget` / `HudProfile` registry and RON profiles for bus, articulated bus, tram, trolleybus ([design](../../architecture/hud-registry.md)); user can switch widgets on/off in *Settings → Interface*. *(A trolleybus is not recognised from the vehicle data, so its profile is not selected automatically.)*
- [x] Slots: status bar (fades), alerts (one at a time, critical sticky), hints (fade), camera label (1.5 s).
- [ ] **Help and controls overlay** *(the overlay, F1 and Report exist from M-0062; the generation from the bindings is open)* generated from the active bindings and vehicle type; F1 per D-UI-06; *Report an issue* with a titled dialog and a visible preview, no silent failure (F18).
- [x] Developer panel replaces the always-visible F10 block (off by default, F10 changes the setting); toasts stack without overlap and below modal layers (F22, M-0062) and get a *Details* dialog with Copy and Report.
- [ ] *(pause wiring)* Vehicle menu integrated into *Pause → Vehicle*; menu and pause always release/restore the cursor and simulation state exactly.
- [ ] HUD review checklist for UI-P13 *(the rules are listed in the [HUD registry](../../architecture/hud-registry.md#4-slots-and-layout); sign-off and the glance-time measurement belong to the usability test)* and a measurement of glance time in the usability test.

## ✅ Acceptance Criteria
- The HUD never takes focus (test `the_hud_has_no_focusable_element_except_pointer_only_chrome`), never moves (fixed slots, fixed-height alert box), never covers the centre of the view; contrast ≥ 4.5:1 on both a bright and a dark scene background (computed over both backdrops in `opts-gui`; a rendered test is still open).
- Every key that does something is listed in the help overlay (generated, so it cannot lag).
- No permanent debug output in a default run (the F10 block is off by default; test `the_developer_panel_is_off_by_default_and_f10_changes_its_setting`).
