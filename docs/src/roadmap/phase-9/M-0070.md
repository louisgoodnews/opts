## 🎯 Objective

The *When* step starts with sensible values: the date and time **defined by the map** (OMSI maps carry a start time/date in their configuration), otherwise the **current date and time** of the device.

## 📦 Deliverables & Tasks
- [ ] Check docs first (`docs/src/formats/map/`) for the map's time/date fields; if missing or unclear, resolve by corpus analysis and document before coding.
- [ ] Map reader exposes `default_start: Option<(date, time)>`; add fields to the catalogue schema if cached.
- [ ] Wizard *When*: preselect map default when present, else the device's current local date and time; show the source ("Map default" / "Now") next to the value; changing the map updates the preselection unless the user already edited the fields.
- [ ] Tests: map with and without defaults; map switch; user override stays.

## ✅ Acceptance Criteria
- Selecting a map with a defined start time shows exactly that time; a map without one shows the local time at wizard open (within one minute); the source label is correct in both cases.
