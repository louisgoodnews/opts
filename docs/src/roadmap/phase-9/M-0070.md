## 🎯 Objective

The *When* step starts with sensible values: the date and time **defined by the map** (OMSI maps carry a start time/date in their configuration), otherwise the **current date and time** of the device.

## 📦 Deliverables & Tasks
- [x] Check docs first (`docs/src/formats/map/`) for the map's time/date fields; if missing or unclear, resolve by corpus analysis and document before coding.
- [x] Map reader exposes `default_start: Option<(date, time)>`; add fields to the catalogue schema if cached.
- [x] Wizard *When*: preselect map default when present, else the device's current local date and time; show the source ("Map default" / "Now") next to the value; changing the map updates the preselection unless the user already edited the fields.
- [x] Tests: map with and without defaults; map switch; user override stays.

## ✅ Acceptance Criteria
- Selecting a map with a defined start time shows exactly that time; a map without one shows the local time at wizard open (within one minute); the source label is correct in both cases.

## 📝 Outcome (2026-10-18)

- **What a map defines:** `global.cfg` has no start time or date. The only clock a map carries is the `[time]` block of `laststn.osn` (45 of 47 installed maps), documented with its corpus statistics in [global-cfg](../../formats/map/global-cfg.md#the-time-block-as-the-maps-start-time-m-0070-corpus-2026-10-18-c). Its saved year lies outside the map's `[years]` for 13 of 36 maps, so only the **time of day** is used.
- **Decision (project lead, 2026-10-18):** time of day from `laststn.osn`, else the current local time; the **date keeps the map default date** (today shifted by `[realyearoffset]`, clamped into `[years]`, decision C6). Whether OMSI itself starts at that saved time is open (Q-G08).
- **Reader:** `opts_core::formats::map::OsnTime::parse` (first 4 KB of the file, corpus test `osn_corpus.rs`), read once per map by `MapEra::read` in the map step; no catalogue schema change (the file is tiny and the read is cached per session).
- **Wizard:** choosing a map sets hour and minute unless the user edited the time or a remembered drive brought it (`PlannerState::time_chosen`); a label under the time says *Map default* or *Now* (`TimeSourceLabel`).
- **Tests:** parser unit tests, corpus test, planner unit test, three wizard tests (current time without a map clock, map clock and label, map switch with and without a user edit).
