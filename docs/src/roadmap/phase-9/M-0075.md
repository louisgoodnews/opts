## 🎯 Objective

The HUD place label shows the **name of the map entry point where the active vehicle was spawned**, not a fixed string. Today it always reads 'Spandau Westerwaldstraße/Siegener Str.' (a hard-coded value).

## 📦 Deliverables & Tasks
- [ ] Find and remove the hard-coded string (HUD session/status widget, `hud/`, `in_game/`); no map-specific literal may remain in the code (source test over the HUD sources).
- [ ] Source of the label: the active session vehicle's `spawn_entry_name` (entry point record of the map; see the map format docs for the entry-point name field and its language/encoding).
- [ ] **Lifetime rule:** the label is shown while the vehicle is at its spawn place; it disappears as soon as the vehicle has moved away (threshold of e.g. 25 m or the first movement, documented) or is despawned, and stays hidden until a new vehicle is spawned; a respawn shows it again.
- [ ] No active vehicle (map-only session) shows no label.
- [ ] Tests: spawn → label equals entry name; drive away → hidden; despawn → hidden; respawn → shown; control protocol `hud.state` exposes it.

## ✅ Acceptance Criteria
- On any map the label equals the chosen entry point's name and follows the lifetime rule; no map name appears anywhere in the HUD sources.
