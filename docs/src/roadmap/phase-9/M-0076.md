## 🎯 Objective

The loading screen names the vehicle that was selected (or *no vehicle*) from the first frame. Today it shows the MAN SD77 first and changes to the real vehicle after about 70 % of the progress.

## 📦 Deliverables & Tasks
- [ ] Find the default (hard-coded or fallback vehicle text) and the point in the load sequence where the real selection reaches the screen.
- [ ] Pass the selection (catalogue id, display name, repaint, or *none*) in the load request so the loading screen reads it before any loading step starts; remove the default.
- [ ] Map-only start ([M-0068](../phase-10/M-0068.md)) shows 'No vehicle'.
- [ ] Test: the first rendered loading frame names the selected vehicle for three different selections; a source test forbids a default vehicle name in the loading screen.

## ✅ Acceptance Criteria
- The vehicle line never changes during loading and never shows a vehicle that was not selected.
