## 🎯 Objective

Replace the menu-of-screens by one shell and a short, honest path from start to driving.

## 📦 Deliverables & Tasks

### Phase A: Specification
- [ ] Turn [flow.md](flow.md) into screen specifications with final copy keys, states and error cases; update `main-menu.md` and `application-startup.md` (they currently deviate from the code).

### Phase B: Shell
- [ ] Navigation rail and screen registry ([expandability §4](expandability.md#4-screen-and-navigation-registry)), back stack, availability rules; banners and the notification service.
- [ ] **Home**: continue card, recent drives, quick drive, installation status.
- [ ] **First run**: OMSI folder found-and-confirm or choose, catalogue progress, welcome.
- [ ] Remove the *Load Game* and *Credits* stubs and the developer copy; **Help → About** with version from the build and licences.

### Phase C: Plan a drive and loading
- [ ] The four-step wizard with persistent summary and remembered choices; search, recents and favourites in lists; vehicles by name with thumbnails; no empty facts; weather and time quick chips; *Live weather* hidden until it works and then opt-in.
- [ ] Master–detail pattern built once in `opts-gui::patterns` and reused by the Library.
- [ ] Loading redesigned: real stages in plain language, themed, **errors kept** (*Ready / Ready with N problems / Failed*), cancel, controls card; fix the map-name mismatch (F17) if reproducible.

### Phase D: In-session flow
- [ ] **Pause overlay** on Esc (never leaves the session), *Leave drive…* with confirmation, end-of-session summary, *Drive again*.
- [ ] Esc semantics of [interaction §6](interaction-and-feel.md#6-control-confirmation-undo) implemented once in the shell; the double-Escape bug (F20) disappears with it.

## ✅ Acceptance Criteria
- Home → Drive → loaded scene in **≤ 2 clicks** with defaults; **1 click** with *Continue*.
- No key or click leaves a running session without a way back; quitting needs a confirmation.
- A seeded load failure is visible to the user and is not overwritten.
- No screen shows placeholder data or a permanently disabled button.
- Golden screenshots of the new screens exist at three sizes and two themes.
