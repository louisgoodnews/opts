## 🎯 Objective

Real settings behind a declarative registry, so a feature adds a setting by declaring it.

## 📦 Deliverables & Tasks
- [ ] `SettingDescriptor` and the registry; generic settings page with categories, search, descriptions, *Reset*, revert prompt for risky settings.
- [ ] Migration of the existing keys (`is_dark_theme` *(already migrated to `theme_mode` by M-0061; new keys `theme_mode`, `auto_light_from`, `auto_dark_from`, `high_contrast`, `theme_file`, `ui_scale`, `density`, `reduced_motion` exist, see the [design system §6.4](../../architecture/gui-design-system.md#64-settings-keys-and-migration))*, `active_theme`, `discovery_interval_days`, `texture_filtering`, `look`, `recent_map_path`, `omsi_path`) with `migrate_from`; old databases keep working.
- [ ] **Graphics**: window mode, resolution, vsync, UI scale, texture filtering, look. **Interface**: theme, accent, density, language, units. **Content**: change the OMSI folder, catalogue interval, rescan, cache size. **Advanced**: developer panel (F10 moves here), logging, file locations (the content of today's *General & Storage*). **Gameplay**: clock, time scale, traffic and pedestrian density.
- [ ] **Controls**: key / gamepad / wheel binding page on the action layer, conflict detection, per-vehicle controls (absorbs the settings part of M-0035).
- [ ] Control-protocol `settings.list/get/set`; generated `docs/src/reference/settings.md` checked in CI.
- [ ] Move the theme, density and accent-preset **labels** (marked `// l10n-ok: UI label … (M-0063)` in `crates/opts-gui/src/theme/`) to message keys with German translations, and remove those markers.
- [ ] **Audio** category appears with M-0027 (capability-gated).

## ✅ Acceptance Criteria
- A new setting is added with a single descriptor and shows up in the UI, persistence, CLI and reference page without other edits (proved by a test fixture).
- Every visible setting works; none is static text.
- Resolution and window-mode changes can be reverted by the 15 s prompt (tested with a fake display).
- Old `settings.db` files load without loss.
