## A. Safety and robustness

- **ISS-001.** Evidence: `crates/opts-bevy/src/control/server/dispatch.rs:75-77` and `:119-120` return from `auth` before `gate()` and the limiter; `server.rs:64` checks only `token.is_none()`, so `""` passes; `server.rs:70` sends the token in plain TCP; `server.rs:83-86` has no connection cap. With a LAN bind this allows brute force, then `shutdown`, input injection, `capture.prune` with `dry_run:false` and save or profile deletes. Next: refuse empty and short tokens (at least 32 random characters); throttle `auth` per peer and globally; until then refuse any non-loopback bind.
- **ISS-002.** Evidence: `control/mod.rs:40-48` defaults to loopback with `token: None`; `app.rs:108-115` starts the server only with `--cli-port`. Any local account can connect. Next: require a token on loopback too, or use a 0600 Unix socket. Test the browser case directly (the line-based reader in `connection.rs:15-27` has no HTTP parsing; the drive-by is suspected, not run).
- **ISS-003.** Evidence: `connection.rs:33-50` loops until EOF; no `set_read_timeout` on the server (only in `opts-cli/src/transport.rs:61-62`); the stop flag cannot wake a thread blocked in `read_line`. Next: 30 s idle timeout, a cap of about 8 connections, and socket shutdown on stop.
- **ISS-004.** Evidence: `opts-cli/src/args.rs:107` (`--cli-token` argv); `commands/table/basics.rs:19-20` (`auth` positional). Next: read the token from an environment variable or a 0600 file.
- **ISS-005.** Evidence: `opts-omsi/src/formats/x/parse/mesh.rs:22` and `:32` call `Vec::with_capacity` on parsed counts with no bound; the binary reader bounds at `MAX_LIST = 50_000_000` (`x/binary.rs:26`, checked at `:104`). Status unverified: no run with a huge count, so the abort is suspected. Next: apply the same bound, or bound by remaining token count, and add a huge-count test.
- **ISS-006.** Evidence: no `fuzz/` directory and no proptest, quickcheck or arbitrary dependency under `crates/`. Pseudo-random tests exist for x, o3d, model and operational; there are no truncation tests for `.bus`, `.sli` or `.hof`. Next: a cargo-fuzz target for `.x`, `.o3d`, `.bus` and the map formats, run when the build lock is free.
- **ISS-007.** Evidence: `control/paths.rs:56` canonicalises only the parent, so an existing symlink is followed by `viewpoints/protocol/transfer.rs:22`, `control_trace/export.rs:17`, `control_drive/state/snapshot.rs:75`. Next: refuse a symlink target, or open with `O_NOFOLLOW`.
- **ISS-008.** Evidence: `save/sections/session.rs:80` joins `map_folder` from save content without a single-component check; `save/sections.rs:58-70` uses an absolute `saved` path. Read-only effect. Next: validate `map_folder` as one normal component and reject absolute paths.
- **ISS-009.** Evidence: `in_game/omsi_world/rail/player_track.rs:22` `expect("lane exists")` on a per-frame path. Suspected safe. Next: `let Some(l) = ... else { return false };`, as line 15 already does.
- **ISS-010.** Evidence: 787 locked packages; duplicate majors (syn, ron, toml, thiserror, rand, notify, nix, hashbrown, windows-sys); `deny.toml` multiple-versions is `warn`; no advisory database cached; font licence notices not checked against an About screen. Next: `cargo deny check advisories` when network is available; confirm notices in the binary.
